# Embedding-Space vs. Accuracy-Based Drift Detection for Open-Source LLMs
### AITR Lab 02 — MRA14 | AI Tools for Research (Post Mid-Semester Assignment)

---

## Research Question

> **Do embedding-space distributional metrics (JSD, MMD) provide earlier and more reliable detection of task-performance degradation than accuracy-based monitoring in open-source LLMs under controlled domain distribution shift?**

## Limitations

- Results are for GPT-2-family models only; generalization to larger instruction-tuned models is not tested.
- Drift is simulated via domain keyword partitioning, not real temporal API drift.
- Thresholds are calibrated at the 95th percentile of reference-window statistics.
