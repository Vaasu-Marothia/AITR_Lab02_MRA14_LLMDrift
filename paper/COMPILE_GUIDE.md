# Overleaf Setup Guide

Your paper is in `paper/main.tex` with `paper/references.bib`.

## Option A — Compile Locally (pdflatex + bibtex)

```bash
cd paper

# First compile pass
pdflatex main.tex

# Generate bibliography
bibtex main

# Two more passes to resolve cross-references
pdflatex main.tex
pdflatex main.tex
```

Requires: LaTeX distribution (MikTeX on Windows, TeX Live on Linux/Mac)  
Download MikTeX: https://miktex.org/download

---

## Option B — Compile on Overleaf

1. Go to https://www.overleaf.com and sign in
2. Click **New Project → Upload Project**
3. Create a `.zip` of the `paper/` folder:
   ```
   paper/
   ├── main.tex
   ├── references.bib
   └── figures/
       ├── roc_gpt2medium.pdf
       ├── ablation_gpt2medium.pdf
       ├── timeline_gpt2medium.pdf
       └── task_performance.pdf
   ```
4. Upload the zip to Overleaf
5. Set compiler to **pdfLaTeX** (Project Settings → Compiler)
6. Click **Recompile**

---

## Figures

Figures are generated by `python scripts/04_evaluate_results.py`  
They are saved to `results/figures/` as both `.png` and `.pdf`.

**Copy PDFs to `paper/figures/` before compiling.**

```
# Windows (PowerShell)
Copy-Item results\figures\*.pdf paper\figures\
```

## LaTeX Package Requirements

The following packages are used (all standard, included in MikTeX/TeX Live):
- `IEEEtran` (document class)
- `cite`, `amsmath`, `amssymb`, `amsfonts`
- `graphicx`, `textcomp`, `xcolor`
- `booktabs`, `multirow`
- `url`, `hyperref`, `float`
- `algorithm`, `algorithmic`
